# ComputeWeave.Core

[English](https://github.com/routersys/ComputeWeave/blob/main/src/ComputeWeave.Core/README.md) | 日本語

ComputeWeave の各パッケージが共有する基本型と内部基盤を収めたパッケージです。他のパッケージの推移的な依存先であり、開発者が直接参照することは想定していません。

このフォークが追加した宣言的な層はここには含まれません。計算パイプライン、資源スロット、Direct3D 11との相互運用、GPUメモリの予算管理はすべて [ComputeWeave](https://www.nuget.org/packages/ComputeWeave) パッケージにあります。

APIの一覧は[リポジトリ](https://github.com/routersys/ComputeWeave)にあります。
